# HostMate AI - Professional Website

A modern, professional website for HostMate AI - the intelligent hosting assistant that automates guest communications and property management.

## 🚀 Features

- **Modern Design**: Clean, professional interface with tech-focused aesthetics
- **Responsive**: Fully responsive design that works on all devices
- **Fast**: Built with Vite for optimal performance
- **Accessible**: Proper semantic HTML and ARIA labels
- **SEO Ready**: Optimized meta tags and structured content

## 🛠️ Tech Stack

- **Framework**: React 19 with TypeScript
- **Styling**: Tailwind CSS
- **Build Tool**: Vite
- **Icons**: Unicode emojis (minimal usage as requested)

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎨 Design Philosophy

- **Professional**: Clean, corporate aesthetic suitable for B2B SaaS
- **Tech-Focused**: Modern gradients, subtle animations, and tech color palette
- **Minimal Emojis**: Only essential emojis used, focusing on clean typography
- **Performance**: Optimized for fast loading and smooth interactions

## 📱 Sections

1. **Hero**: Compelling headline with clear value proposition
2. **Features**: 6 key features with hover animations
3. **App Showcase**: Visual representation of mobile app screens
4. **Testimonials**: Social proof from satisfied users
5. **Pricing**: Clear pricing tiers with founder special offer
6. **CTA**: Strong call-to-action section
